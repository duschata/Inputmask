Open this MCVE in CodePen / JSFiddle

The issue template of this project asks for a codepen or jsfiddle link. Open this file in a browser and press a button: it posts the reproduction to that service's prefill API, which opens a pre-filled editor in a new tab. Save it there and use the link.

Unlike index.html next to this file, the playground loads Inputmask from a CDN rather than from dist/ — so it demonstrates a published release, not this checkout. The <script src> is part of the transferred HTML on purpose: an editor's “external resources” setting is easy to overlook, and anyone reading the pen should see which build is under test.


5.1.0-beta.17 is the current development state and the build this report is against. 5.0.10 is the latest stable release, 5.0.7 the first affected one, 5.0.6 the last one without the defect.

CodePen needs a (free) account to save, JSFiddle does not. If a prefill API ever stops accepting the post, copy the two blocks below into the editor by hand — they are self-contained, no external-resource setting needed.
